# Предпроект по саду: пример результата

Интерактивная страница показывает, как выглядит результат предпроектной диагностики промышленного яблоневого сада: решение по каждому кварталу, уровень уверенности и бюджетную рамку на сезон.

**Данные условные.** Сад, кварталы и цифры смоделированы, чтобы показать формат и логику решений. Совпадения с реальными хозяйствами случайны.

## Что на странице

- **Итог по решениям**: Core (25+ т/га уже сейчас), Усиление (может дотянуть до Core с полной программой), Санитарный минимум, Кандидаты на вывод, а также «серая зона», которую нужно проверить весной.
- **Карта решений по кварталам**: цветом показано решение, штриховкой «нужна проверка». По клику на квартал открывается его паспорт. Есть режим «Программа», где видно, какие кварталы попадают в выбранный сценарий бюджета.
- **Паспорт квартала**: исходные данные, урожай по годам, уровень квартала в нормальный год с интервалом 90%, вероятность держать 25+ т/га, карта потерь от ориентира сорта до уровня квартала, рекомендации на зиму и весну.
- **Бюджетная рамка**: полная программа на 300, 400 или 500 га при нормативе 150 или 200 руб/дерево, остальная площадь на санитарном минимуме.
- **Погода года отдельно от квартала** и **сравнение со средним**: почему решение принимается по оценке модели, а не по среднему урожаю за годы.
- **Матрица решений** по всем кварталам: с сортировкой, поиском и фильтрами.

Выбранный квартал, сценарий и норматив сохраняются в адресе страницы, поэтому ссылкой можно поделиться в нужном виде. Например, `?q=5-04&s=500&m=program`.

## Метод

Уровень квартала оценивается смешанной моделью по многолетним данным, по аналогии с племенной ценностью в селекции: квартал отделяется от погоды года, сорта и возраста.

```
log(урожай) - log f(возраст) = сорт + год + квартал + остаток
```

Здесь `f` - кривая выхода сорта на плодоношение, а случайный эффект квартала (BLUP) дает его уровень в нормальный год. Короткая история квартала «стягивается» к среднему по его сорту и возрасту, поэтому интервал у таких кварталов шире.

## Структура

```
index.html               страница
css/style.css            стили, светлая и темная тема
js/dash-shim.js          загрузка данных и параметры в адресе
js/app.js                карта, паспорт, графики, таблицы
data/*.json              условные данные
assets/d3.v7.9.0.min.js  D3 v7.9.0 (лицензия ISC, assets/d3-LICENSE.txt)
scripts/generate_data.py генерация условных данных и расчет модели
```

## Локальный запуск

Страница загружает данные через `fetch`, поэтому ее нужно открывать через локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Пересчет данных

```bash
pip install numpy pandas scipy statsmodels
python3 scripts/generate_data.py
```

Генератор детерминированный (фиксированное зерно), поэтому повторный запуск дает те же файлы в `data/`.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория). Страница помечена `noindex`, чтобы не попадать в поисковую выдачу. Чтобы ее индексировали, уберите этот тег из `index.html`.
